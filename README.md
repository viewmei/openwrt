# OpenWrt SBE1V1K Build

This is an automated build repository for OpenWrt on the Askey SBE1V1K (Spectrum RTQ7300T) router.

## Device Information

- **Device**: Askey SBE1V1K / Spectrum RTQ7300T
- **SoC**: Qualcomm IPQ9570
- **RAM**: 2GB Micron
- **Storage**: 8GB eMMC
- **Ethernet**: 
  - 1x 10G RTL8261BE
  - 1x 2.5G QCA8081
  - 2x 1G QCA8075
- **Wi-Fi**:
  - QCN6214 2.4GHz 4x4
  - QCN6274 5GHz 4x4
  - QCN6274 6GHz 4x4

## Build Status

Automated builds are triggered on push and scheduled builds.

## Based On

This repository is based on the SBE1V1K support from [andrewjlamarche/openwrt](https://github.com/andrewjlamarche/openwrt/tree/sbe1v1k)
